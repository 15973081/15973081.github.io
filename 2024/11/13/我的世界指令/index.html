我的世界指令

🎯 基础玩法

  • /tp <目标> <x> <y> <z>
    快捷瞬移至指定坐标，或传送玩家之间。

  • /gamemode <creative|survival|adventure|spectator> [玩家]
    自由切换游戏模式，适合测试和创造玩法。

  • /time set <day|night|数字>
    快速调整白天/黑夜时间，便于建筑或探索。

  • /weather <clear|rain|thunder> [持续时间]
    控制气候变化，制造氛围或剧本场景。

  • /difficulty <peaceful|easy|normal|hard>
    一键调整难度，轻松关闭敌对生物。

📦 资源与状态

  • /give @s minecraft:<物品ID> <数量>
    获得任意物品或方块，自定义资源自由度极高。

  • /effect give @s <效果> <秒数> <等级>
    给予夜视、速度等增益状态，支持批量附加。

  • /enchant @s minecraft:<附魔ID> <等级>
    为手持物品添加附魔效果，提升战力与耐久。

🛠 建筑与结构

  • /fill <x1> <y1> <z1> <x2> <y2> <z2> <方块>
    批量填充方块区域，快速建造地基或挖掘空间。

  • /clone <x1> <y1> <z1> <x2> <y2> <z2> <目标x> <目标y> <目标z>
    复制并粘贴结构，轻松复刻建筑。

  • /setblock <x> <y> <z> <方块>
    设置单一方块，适合调试或精细搭建。

  • /locate <structure|biome> <名称>
    查找最近的地标结构或生物群系，节省探索时间。

🛡 管理与调试

  • /list
    查看当前在线玩家列表，方便交流与管理。

  • /kick <玩家> [原因] / /ban <玩家> / /pardon <玩家>
    管理玩家权限，维护服务器秩序。

  • /op <玩家> / /deop <玩家>
    授予或撤回管理员权限。

  • /save-all, /stop, /reload
    保存世界、关闭服务器或重新加载设置。

📘 Bedrock & 教育专用

  • /ability <目标> mayfly|mute|worldbuilder true/false
    开启飞行、静音或建造权限（教育版支持）。([edusupport.minecraft.net][4])

  • /camerashake <玩家> <强度> <持续时间> [类型]
    触发镜头抖动效果，营造震撼/disturbance（Bedrock/教育版）。([beebom.com][5])

  • /alwaysday / /daylock
    锁定昼夜周期（日照永恒版本）。

  • /toggledownfall
    切换雨雪效果（Bedrock 专属）。

💡 使用建议

  1. 生存 / 探索

    • /time set day + /gamerule keepInventory true + /locate village → 持续挂机生存线索。

  2. 创意 / 建筑

    • 配合 /fill + /clone + /execute 批量建造复杂结构。

  3. 服务器管理

    • /op + /kick + /ban + /save-all 保障环境稳定与数据安全。

⚙ 高级 & 自动化

  • /execute … run …
    强力命令执行器，支持条件检测、嵌套触发、复杂脚本。比如：

“命令虽有边界，你的想象无限。”
从普通玩家到世界设计师，只需一行 /execute，开启你的《我的世界》传奇！
