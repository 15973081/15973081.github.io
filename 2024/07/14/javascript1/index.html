javascript的学习(认识)

🚀 第一章：初识 JavaScript

本章带你了解浏览器如何执行 JavaScript、JS 的三大组成部分、脚本写法、变量、注释及输入输出的基础知识。

1.1 浏览器中的 JavaScript 执行流程

浏览器主要由两大核心引擎构成：

  • 渲染引擎（Rendering Engine）：负责解析 HTML、CSS，生成 DOM 和页面布局
    • 例如：Chrome 使用 Blink（原基于 WebKit）:contentReference[oaicite:0]{index=0}
  • JS 引擎：读取并执行 JavaScript 代码，通常使用即时编译（JIT）技术
    • Chrome 的 JavaScript 引擎是 V8，擅长将 ECMAScript 转换为机器码:contentReference[oaicite:1]{index=1}
  • 在 Chrome 的渲染进程中，Blink 和 V8 协同工作，共同驱动页面解析和脚本执行:contentReference[oaicite:2]{index=2}

1.2 JavaScript 的三大组成 🌐

  1. ECMAScript：JavaScript 的核心语言规范，由 ECMA 国际组织发布，是语言语法与行为基础:contentReference[oaicite:3]{index=3}。
  2. DOM（文档对象模型）：将 HTML 页面结构映射为对象树，允许通过 JS 动态操作页面元素:contentReference[oaicite:4]{index=4}。
  3. BOM（浏览器对象模型）：提供与浏览器窗口、地址栏、历史记录、弹窗等交互的接口，如 window、navigator、location 等:contentReference[oaicite:5]{index=5}。

1.7 数据类型（2.0预告）

JavaScript 数据类型主要分为两类：

  • 原始类型：Number、String、Boolean、Undefined、Null
  • 复杂类型：对象（如数组 Array、日期 Date、函数 Function 等）

📌 小结

  • 浏览器利用渲染引擎 Blink 和 JS 引擎 V8 来处理页面内容和脚本逻辑。
  • JS 包含 ECMAScript、DOM 和 BOM 三大核心组成。
  • 推荐使用外部 JS 文件，并掌握注释规范、变量声明、断点调试及格式化输出等基础。
