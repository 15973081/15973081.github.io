对象定义

JavaScript 中的对象分为三类：

  • 自定义对象
  • 内置对象
  • 浏览器对象

前两者属于 ECMAScript 标准，第三种属于浏览器提供的 API。

内置对象 是 JS 语言自带的对象，提供了最基本和必要的功能，帮助我们快速开发程序。常见的内置对象包括：Math、Date、Array、String 等。

简单类型与复杂类型

基本概念：值类型 vs 引用类型

  • 值类型（Primitive）：存储实际值，常称为基本数据类型，包括 string, number, boolean, undefined, null, Symbol, BigInt。
  • 引用类型（Reference）：存储的是指向堆内存中对象实例的地址，包括对象（Object）、数组（Array）、函数（Function）、Date 等。

简单类型变量直接持有数据，而复杂类型变量则持有指针，指向真正的数据对象。

11.2 内存存储：栈 vs 堆

  • 栈（Stack）：存放值类型和调用栈，空间固定、访问快，如：数字、字符串字面量、变量地址等。
  • 堆（Heap）：存放复杂类型的数据结构，空间动态、访问相对慢，由垃圾回收机制管理 (javascripttutorial.net, academind.com)。
