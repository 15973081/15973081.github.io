React组件

React 组件系统详解笔记

📘 类组件

一、类组件定义

类组件使用 class 进行声明，必须继承自 React.Component，且包含 render() 方法。

二、类组件的调用

类组件执行流程

  1. 遇到 <App />，先实例化类组件。
  2. 调用其 render() 方法。
  3. render() 的返回值将替换组件标签位置进行渲染。

🧮 函数组件

一、函数组件定义

函数组件本质上是一个函数，返回值为要渲染的 JSX。

二、函数组件的调用

函数组件通过 <App /> 调用，其返回值即为渲染内容。

⚖️ 函数组件和类组件的区别

区别项 类组件 函数组件
执行方式 实例化后调用 render 直接调用函数
this 使用 有，指向当前组件实例 无（默认 undefined）
状态（state） 有 无（需使用 Hooks）
生命周期 有 无（Hooks 可模拟）
