React JSX基础使用指南

一、JSX 概念

JSX = JavaScript + XML

作用：方便快速创建 React 元素（虚拟 DOM）。

XML 是一种数据结构表达格式，是 JSON 出现之前常用的通信格式。

2.2 JSX 简易使用样式

2.3 JSX 标签的规则

  • HTML 标签：全小写，如 <div>、<table>
  • 组件标签：首字母大写，如 <Student />、<Header />

2.4 JSX 中的插值表达式

规则：使用 {} 展示 JavaScript 表达式

支持类型：

  • Number, String, Array, null, undefined, boolean
  • 不支持 object, 函数定义 (return 支持)

2.5 条件渲染

单分支：flag && <div>正确</div>

双分支：flag ? <div>正确</div> : <div>错误</div>

多分支：封装成函数

2.6 JSX 插值赋值属性

规则：

  • JSX 属性可以使用插值

结语

JSX 是 React 中极其重要的概念，它使得编写 UI 逻辑更加直观、简洁，同时不失 JS 的强大功能。熟悉它的规则和特性是进入 React 开发不可或缺的步骤。
