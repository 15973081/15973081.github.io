2. 虚拟 DOM 与 React 元素

2.1 什么是虚拟 DOM

虚拟 DOM 是 React 系统里用 JS 对象表示的 DOM 结构，尽可能减少对真实 DOM 的直接操作，从而减少重排和重绘，提高性能。

主要特点：

  • 是一个轻量级对象，包含元素的名称、属性、子元素
  • 可通过 render() 方法渲染为真实 DOM
  • 可通过 React.createElement() 或 JSX 生成
