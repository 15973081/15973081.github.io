CSS 模块化

将 CSS 文件的样式转换成 JS 模块来使用，能够有效避免不同组件之间使用相同样式名时发生冲突，保证每个组件样式的独立性。

CSS 模块化的好处

  • 避免样式名冲突
  • 保持组件样式的封闭性和独立性
  • 方便样式管理和维护

实现步骤

  1. 命名规则：CSS 文件需以 xxx.module.css 命名。
  2. 引入样式：使用 import styles from './xxx.module.css' 方式导入。
  3. 使用样式：通过 styles.类名 的形式应用样式。

类组件的生命周期

挂载阶段

执行顺序：

  • constructor 和 componentDidMount 只会执行一次，挂载后不会重复执行。
  • render 在挂载和更新阶段都会执行。

componentDidMount 常见用途：

  • 启动定时器
  • 发送 Ajax 请求
  • 订阅事件
  • 添加事件监听器

若存在父子组件嵌套：

  • 父组件先执行 constructor 和 render
  • 子组件执行 constructor、render 和 componentDidMount
  • 最后父组件执行 componentDidMount

更新阶段

执行顺序：

触发更新的方式：

  • 接收到新的 props
  • 调用 setState 修改状态
  • 使用 forceUpdate 强制更新

componentDidUpdate 可用于：

  • 发送 Ajax 请求
  • 将数据持久化存储

注意：父组件更新时，子组件也会无条件执行 render。

shouldComponentUpdate（了解）

目的：避免无效渲染，提高性能。

PureComponent

继承自 React.PureComponent 的组件会自动实现浅比较，props 和 state 没变化时阻止重新渲染。

卸载阶段

componentWillUnmount 在组件卸载前调用，用于清理：

  • 关闭定时器
  • 取消订阅
  • 移除事件监听

ref 的使用

ref 作用：可以通过绑定 ref 来获取组件中真实的 DOM 元素。

常见三种绑定方式：

  1. 字符串（不推荐）
  2. 回调函数（不推荐，写法繁琐）
  3. React.createRef()（推荐）

4-16-2. 事件对象

React 合成事件对象 e 支持跨浏览器兼容，常见事件属性：

  • e.target：事件源
  • e.currentTarget：事件绑定的元素
  • e.preventDefault()：阻止默认事件
  • e.stopPropagation()：阻止事件冒泡

生命周期方法总结

生命周期 触发时机 作用
constructor 组件实例化时 初始化状态、绑定事件
render 挂载和更新时 返回 JSX
componentDidMount 组件挂载完成后 发送请求、订阅事件
componentDidUpdate 组件更新完成后 响应 props 或 state 变化
componentWillUnmount 组件卸载前 清理定时器、取消订阅
