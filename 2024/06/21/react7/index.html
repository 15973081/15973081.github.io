React Hooks 知识点整理

useState

  • 用于给函数组件创建状态数据。
  • 语法：

  • setXxx 函数两种用法：

    1. setXxx(新值)
    2. setXxx(回调函数)，回调函数接收最新状态，返回新的状态值。
      使用场景：当直接赋值获取不到最新状态时（如闭包问题），应用回调函数方式。

useEffect

  • 模拟生命周期函数：

    • componentDidMount
    • componentDidUpdate
    • componentWillUnmount

  • 可以多次调用，监听不同的依赖。

用法：

  • 无第二参数：每次渲染后执行（componentDidMount + componentDidUpdate）
  • 空数组第二参数：只在挂载时执行（componentDidMount）
  • 数组指定依赖：监听依赖变化执行（componentDidMount + 监听变化）
  • 返回函数：卸载时执行（componentWillUnmount）

useRef

  • 用于创建ref对象，绑定并获取真实DOM元素。
  • 引入：import { useRef } from 'react'
  • 创建：const ref = useRef()
  • 绑定：<input ref={ref} />
  • 访问DOM：ref.current

Hook 使用规则

  • 只能在函数组件或自定义Hook函数中调用。
  • 不可在类组件中使用。
  • 必须在顶层调用，不能在循环、条件或嵌套函数中调用，确保Hook调用顺序一致。

自定义 Hook

  • 本质是函数，但函数名必须以 use 开头。
  • 可以在自定义Hook内部使用其他Hooks。

Context（上下文）

  • 用于祖先组件向后代组件传递数据，避免层层传递props。
  • 创建：const context = React.createContext()
  • 提供数据：用 context.Provider 包裹后代组件并传递 value。
  • 使用数据：后代组件通过 useContext(context) 获取数据。

pubsub（发布订阅）

  • 用于任意组件间通信。

  • 通过发布-订阅模式实现。

  • 安装：npm i pubsub-js

  • 导入：import PubSub from 'pubsub-js'

  • API：

    • 订阅：let token = PubSub.subscribe('消息名', (msg, data) => {})
    • 发布：PubSub.publish('消息名', 数据)
    • 取消订阅：PubSub.unsubscribe(token) 或 PubSub.unsubscribe('消息名')
    • 取消所有订阅：PubSub.clearAllSubscriptions()
