Spring Boot 集成 WebSocket 实现双向通信

一、WebSocket 简介

WebSocket 是建立在 TCP 连接上的一种网络通信协议，旨在实现客户端与服务器之间的全双工通信。与传统的 HTTP 请求-响应模式不同，WebSocket 只需完成一次握手，即可建立一条持久的连接通道，之后双方就可以任意时刻互发消息。

::: tip
全双工通信意味着数据可以同时在两个方向传输，例如客户端向服务端发送消息的同时，服务端也能主动推送消息给客户端。
:::

相比之下，单工通信只允许信息单向传输，不能支持即时响应或实时推送，这在实时聊天、推送通知、直播数据等场景中存在严重局限。

二、WebSocket 协议的核心特点

WebSocket 具备以下几个关键特性，使其在实时应用开发中广泛应用：

  • 基于 TCP，属于应用层协议，实现简单、稳定。
  • 兼容 HTTP 协议，握手阶段通过 HTTP 发起，默认端口也是 80/443，易于被代理服务器接受。
  • 数据结构轻量，通信高效，适合频繁交互的场景。
  • 支持 文本和二进制数据 传输。
  • 无同源限制，前端可连接任何 WebSocket 服务端。
  • 使用协议标识符 ws:// 或 wss://（加密），连接地址为标准 URL 格式。
