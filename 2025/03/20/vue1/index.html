🍋 Vue 2 快速入门教程

🎯 学习目标

  • 初步了解 Vue.js 的数据绑定功能
  • 掌握 Vue 应用的基本结构与开发方式
  • 理解声明式渲染、单向数据绑定与双向数据绑定的核心概念
  • 掌握基本的事件绑定方式

📦 开发环境准备

  1. 安装 Vue 插件（适用于 IDEA 或 WebStorm）

    • 插件名称：Vue.js
    • 用于提升开发体验，支持模板语法高亮、组件提示等功能。

  2. 准备项目结构

    • 新建一个空文件夹作为项目目录

    • 将其拖入 IDEA 中打开

    • 下载并引入 Vue.js（开发版本）：

      • 官方下载地址：Vue.js 官网

🧪 示例一：数据绑定机制验证

文件名：quick_start.html

✅ 功能说明

  • 演示 Vue 的插值表达式 {{ }} 绑定 data 中的数据。
  • 通过 new Vue({}) 创建 Vue 实例，并挂载到 DOM 元素上。

💡 小贴士

  • Vue 实例需要先挂载 DOM，再执行数据绑定。
  • 插值表达式 {{ }} 是最基础的数据绑定方式，用于将 JS 数据渲染到页面中。
  • 如果数据找不到匹配项，会显示为空。

🔁 示例二：单向数据绑定 (v-bind)

文件名：data_bind.html

✅ 功能说明

  • 使用 v-bind 绑定 DOM 元素属性（如 src, width 等）
  • 简写形式：:src、:width

💡 注意事项

  • 插值表达式 {{ }} 不能用在 HTML 属性上。
  • 属性绑定必须使用 v-bind 或其简写形式 :属性名。

🔄 示例三：双向数据绑定 (v-model)

文件名：two_way_binding.html

✅ 功能说明

  • 使用 v-model 实现数据和视图的双向绑定

🔍 机制解读

  • v-model 会自动绑定 input 的值与 data 中的变量，实现输入即更新视图。

  • 底层依赖两个核心机制：

    • Data Binding：数据变动 → DOM 更新
    • DOM Listeners：DOM 变动（如用户输入） → 数据更新

🔘 示例四：事件绑定

文件名：event.html

✅ 功能说明

  • 使用 v-on 绑定事件
  • 简写形式：@click

🔍 补充说明

  • 事件绑定方式：

    • 完整写法：v-on:click="方法名"
    • 简写方式：@click="方法名"

  • 若无参数，可省略 ()。

🧠 Vue 事件处理机制

  • Vue 底层仍依赖原生 DOM 事件系统，封装了一套更方便的绑定语法。
  • 可监听多种事件如 @input、@change、@keyup.enter 等。

📎 常见开发提示

  • div 要在 script 之前加载，否则 Vue 实例无法正确挂载。
  • 插值表达式不能绑定到属性，需用 v-bind。
  • 使用开发者工具可查看 $el、$data、子节点等信息，辅助调试。
  • Vue 的优势在于声明式编程、数据驱动视图的简洁开发模型。
