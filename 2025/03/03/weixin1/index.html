本文由马云南撰写，记录了我在从零开始学习和开发微信小程序过程中的所见所学，旨在为初学者提供一条清晰易懂的入门路线，附带开发者角度的细节分析与实操建议。

一、小程序起步

1.1 小程序简介

1.1.1 小程序与普通网页开发的区别

维度 网页开发 小程序开发
运行环境 浏览器 (Chrome、Safari) 微信客户端
可调用 API DOM/BOM、Web Storage等 微信 API（扫码、支付等）
开发工具 任意文本编辑器 + 浏览器 微信开发者工具

由于小程序运行在微信独立环境中，它不能直接使用浏览器的 BOM 或 DOM API，因此必须使用微信提供的组件和接口。

1.1.2 体验小程序

开发初期建议通过微信扫码预览已有优秀小程序（使用微信 6.7.2 及以上版本），快速感受交互和页面逻辑。

1.2 第一个小程序

1.2.1 注册开发帐号

进入 微信公众平台，点击“立即注册”，选择“小程序”类型，填写邮箱、主体信息并完成邮箱激活。注册完成后可获得 AppID。

1.2.2 安装开发者工具

前往 微信开发者工具下载页面，下载稳定版本安装。

安装成功后：

  1. 使用微信扫码登录；
  2. 根据喜好设置主题（推荐暗色模式，适合长时间开发）；
  3. 如公司环境需要，设置 HTTP 代理。

1.2.3 创建第一个项目

在微信开发者工具中新建项目：

  • AppID 可选择无 AppID 模式进行测试；
  • 设置项目目录，建议英文命名；
  • 默认模板建议选择“Hello World”模板。

创建完成后会看到：

  • 项目结构树（pages、utils、app.js 等）；
  • 页面预览（模拟器区域）；
  • 控制台（调试日志）。

点击工具栏的“预览”，通过手机扫码可在真机查看效果。

1.2.4 小程序代码结构详解

项目主要包含：

  • app.js：全局 JS 脚本（如监听生命周期、全局函数）
  • app.json：全局配置文件（如页面路径、窗口样式、TabBar）
  • app.wxss：全局样式文件（类似 CSS reset）
  • **pages/**：页面模块，每页对应 4 个文件（.js/.json/.wxml/.wxss）
JSON 配置文件用途
  • app.json：配置全局页面路径、导航栏、窗口样式等；
  • project.config.json：微信开发工具项目配置；
  • sitemap.json：SEO 搜索引擎收录配置；
  • 页面级 .json：配置单页的导航栏标题、颜色、是否开启下拉刷新等。

1.2.5 小程序宿主环境解析

什么是宿主环境

微信客户端为小程序提供运行平台，包括内置浏览器核心、API 接口封装、页面渲染机制等。

通信机制
  • 主体包括：渲染层、逻辑层（WebView 与 JSBridge）
  • 页面渲染使用数据绑定及事件驱动机制
小程序启动流程
  1. 拉取配置与资源包
  2. 初始化 app 实例
  3. 加载指定首页
组件基础
  • view、text、image、scroll-view、swiper 等组件是页面构建基础；
  • 每个组件支持不同属性与事件绑定，满足不同 UI 场景需求。
API 简介

微信提供如 wx.request、wx.navigateTo、wx.login 等接口用于数据请求、页面跳转、用户认证等。

1.3 开发协同与上线

协同开发机制

  • 成员角色：管理员、开发者、体验者；
  • 开发流程：本地开发 → 上传代码 → 设置版本 → 提交审核 → 正式发布。

添加体验成员

登录公众平台后台 > 用户身份管理 > 添加成员（支持微信扫码验证身份）。

发布上线步骤

  1. 使用开发者工具上传代码；
  2. 在后台填写版本描述并提交审核；
  3. 审核通过后可一键发布正式版本；
  4. 使用小程序码推广，支持渠道统计。

运营数据查看

  • 方式一：小程序数据助手小程序
  • 方式二：公众号后台 > 数据分析 > 用户分析、访问分析、转化率分析等
